# ai-sandbox

Sandbox for AI-related proofs-of-concept exploring how LLM-powered agents
can assist with OpenShift telco workflows.

## Getting Started

Start with the [rh-telco plugin README](agentic-plugins/rh-telco/README.md).

## Projects

| Project | Description |
|---------|-------------|
| [agentic-plugins](agentic-plugins/) | Agentic plugins registered in Compass and published to the [Red Hat agentic catalog](https://github.com/RHEcosystemAppEng/agentic-catalog/tree/rc/v1.0.0). `rh-telco` carries the `rds-policy-update` skill and its validation hook. |
| [rds-policy](rds-policy/) | Design docs and promptfoo evals for the `rds-policy-update` skill (AI-driven Day 2 policy updates for OpenShift RDS version upgrades). |
